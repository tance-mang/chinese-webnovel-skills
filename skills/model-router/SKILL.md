# 模型分工

根据任务、现有配置和作者对数据外发的选择推荐模型。程序接口和有独立电脑的研究代理是两种入口。先核对所选服务可访问的模型、配置与任务范围。模型能力未实测时标待核实。提供 [CLI 操作](../../cli/README.md) 和 [Grok Bot 交接](../../integrations/grokbot/README.md)。

作者已选择 Grok 写小说时，交给 [grok-write](../grok-write/SKILL.md) 执行。用 `--grok --models` 查询该账号可见的模型，再对指定任务调用。

发给其他服务前让作者选定需要的材料，尤其是未发表正文和角色档案。模型切换显式确认；不要因限流、无权或拒绝而自动改派。比较时固定输入与评审维度，结果匿名保存为备选，不自动采用或并入正文。
