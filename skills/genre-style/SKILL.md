# 英文类型风格

读取仓库根目录的 [类型档案](../../references/english-genre-profiles.md)。按作者指定的类型选择档案。混合类型以本场景承担的叙事任务选主档，再加一个副档的长处。类型不明且影响成稿时，先给两种方向及取舍。

交付可覆写的风格卡：主／副类型、读者承诺、视角与距离、叙事速度、角色对白与情绪、章尾推进、作者明确的边界。作者给出的样稿和偏好优先。用原文的一处细节解释建议，不以固定句长比例、段长、转折频率或每章悬念判分。若要投稿，单独查当前平台规则，不把类型经验当作政策。
