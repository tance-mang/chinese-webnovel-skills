# 英文网文出海（english）

帮中国作者写**目标平台读者愿意往下看**的英文，而不是「中文翻译腔」。常见差异仍是：**中文卖剧情爽点，英文连载常常卖情绪钩子**——这是偏好，不是所有类型的硬规则。规则与平台表调 `references/english-webfic.md`；已核验出处见 `integrations/grokbot/overseas-research.md`。

## 三条路径（先选一条）

动手前先声明走哪条。三条路径的验收标准分开，不要混成「反正写成英文」。

| 路径 | 何时用 | 验收 |
|---|---|---|
| **original** | 直接按目标类型写英文新故事 | 像该类型的英文作品，不是中文梗的逐句对译 |
| **adapt** | 已有中文故事，要保住核心因果和人物动机，用英文重讲 | 文化层先选：保留中国 / 混合 / 转目标文化。先列决策表（称谓、制度、梗、境界术语）再改正文。不擅自改动机和事件因果 |
| **translate** | 要保住事实、情节和叙述声音 | 优先自然英语；术语锁定后全书一致。不借润色改情节 |

`globalize`（文化改编决策）和 `intimacy`（成年角色亲密场景任务卡）本轮只在研究报告里有草案，**还没有独立技能**。需要细则时读 `integrations/grokbot/overseas-research.md`，不要假装这两个技能已经可以调用。

## 偏好，不是全英文硬规则

写英文时默认用目标类型的叙事习惯，而不是「中文思维 → 逐句翻译」。

- 连载网文**常用**动作、对话、冲突，少解释、少空抒情。作者可以按类型改。
- `english-webfic.md` 第〇节的十条是**默认偏好**。其中「句长 70/20/10」「每 200 字必须推进」「每段或每章强钩」**不再是硬配额**。按类型表覆盖：Wattpad Romance 可以有生活句；Royal Road LitRPG 允许把规则和结算写完整；KDP Romance 按整本弧线，不按日更卡点切碎。
- 「谜团 → 情绪 → 爽点」和成长包装（Survivor / Underdog / Outcast / Chosen One）主要用于英文爽文连载。言情慢热、心理惊悚不必套同一张表。

## 何时用

- 直接写英文（original）
- 中文故事改编（adapt）或翻译（translate）
- 问出海平台怎么选
- 去掉翻译腔 / 机械英文

现行可参考平台：**Wattpad / Royal Road / Webnovel / Amazon KDP**。

**Radish 已停运**（官方于 2025-12-31 关闭），不要推荐新投。公告说明 Tapas 并未因此关闭，但阅读历史和作品**不能**自动迁到 Tapas。不要替作者改投，也不要承诺迁移。

## 用法

### original · 写英文

调 `english-webfic.md` 的类型偏好，而不是一律短句：

- 连载：前段尽快进入事件。完本（尤其 KDP）允许把场景写完。
- 对话一句一行、换行。章标题 `Chapter X`。
- 情绪优先用动作和身体反应，少用抽象总结句。这是文风偏好，不是字数警察。

### adapt · 用英文重讲

保留剧情因果、钩子功能和人物动机。砍的是目标读者读不懂的铺垫，不是人物为什么这么做。文化梗进决策表：保留 / 替换 / 脚注，由作者确认。

### translate · 保事实的自然英语

不改情节。专治翻译腔：情感清单句、反复的 not X but Y、三项排比、称谓直译、境界说明书。术语表锁定后不要每章换译名。

### 去英文 AI 腔 / 翻译腔

标出并改（改法由作者选，不宣称能鉴定「是不是 AI 写的」）：

- 太正式：`Therefore / However / Furthermore`
- 太工整：镜像句式
- 空文学：`Moonlight danced gracefully...`
- 只拆那些按类型显得过载的长段。KDP 和慢热不要为了「短」而拆碎。

### 选平台

- 女性向连载言情 → **Wattpad**（社区发布，上手门槛低）。不要再推荐 Radish。
- 男频系统 / LitRPG / Progression → **Royal Road**。同时提醒：性内容不得作为核心或卖点，erotica 禁止；AI 须按平台规则标注 AI-Assisted 或 AI-Generated；标题、简介、章名不要写 mature 卖点。
- 系统 / 重生 / 都市连载 → **Webnovel**。公开 AI 披露规则仍标「待核实」，不要写成「可以不披露」。签约和独家以作者合同为准，不自动建议签约。
- 完结电子书 → **Amazon KDP**。文本、封面或内页图像、翻译若是 AI-generated，必须向 Amazon 披露；**大幅编辑之后仍然要披露**。作者自写、AI 只做润色、校对或头脑风暴（AI-assisted）不必披露。

## 原则

- 像目标类型的英文，而不是像翻译。
- 钩子强度是滑杆，不是所有英文的开关。
- 平台政策以研究报告里的官方出处为准，投稿前再打开原页。
