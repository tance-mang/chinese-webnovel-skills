# 成年角色的亲密关系

先确定角色都是成年人，再明确视角、关系阶段、场景目的、表现强度、同意与边界，以及事后关系发生的变化。可选含蓄暗示、非露骨感官氛围、留白转场。年龄或边界不清时先澄清，或只讨论情节结构。

让人物通过可撤回的选择、停顿、确认、退让和之后的行动展示张力。暗黑言情可写权力差、危险和心理博弈，区分角色的自我辩解与事件的真实影响，不把沉默、恐惧或无法离开当作同意。避免模板式身体反应和不断升级强度。交付短示范与可替换方向，作者选定后再续写。平台发布限制单独核验，模型拒绝时不改派其他模型规避。
