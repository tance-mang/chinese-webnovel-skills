# 中文小说海外本地化

先确认改编范围。只想忠实翻译时走 `english` 的 translate。adapt 支持保留中国背景、文化混合、迁往具体国家和地区三种方案。混合或迁移时明确时间、机构和人物来历，别把“欧美”当同一个制度。

1. 记录来源章节与事实锚点：人物动机、身份与亲属关系、谁知道什么、关键事件先后、物件、代价及世界规则。用短引文或段首定位。
2. 生成双语决策表，列出原文术语或制度、英文表达、保留／解释／替换、影响范围、批准状态。覆盖本稿涉及的姓名称谓、货币、学校、婚俗、法律、网络梗和虚构规则。不要把亲属称谓改成不相干的人，不凭汇率换算改变经济处境。现实制度未核实则标待查。
3. 作者确认会改变身份、地点、制度、事实或后续因果的方案后再应用。信息不足时可先交付保守试译和待决项。作者能逐项撤销，并看到需回改的章节。
4. 交付干净英文正文与分开的改编说明。复核源稿锚点、知识状态及称谓是否保持。只把已采纳决定写入双语档案，见 [档案与样例](../../references/bilingual-adaptation.md)。
