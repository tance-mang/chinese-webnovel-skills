# 英文母语化编辑

读目标类型、英语变体、原文和作者想保留的口吻；需要时加载 [类型档案](../../references/english-genre-profiles.md)。检查搭配、直译、文化制度、人物声线、对话、视角、时态、节奏与情绪连续性。不要将地域英语、人物口音或作者有意使用的节奏当成错误。

按客观错误、可选编辑建议、风格偏好分类。每条写位置、原句、影响和候选改法。时态跳转如有明确叙事原因可保留；不以写法推断 AI 作者身份。作者要求精修时只改指定范围，保持事实、叙事信息量和说话人的目的。正文、说明和备选分别输出，未经作者采纳不回写档案。
